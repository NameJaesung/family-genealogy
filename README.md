# 전주이씨 해안군 정희공파 가족 족보

집안에 전해 내려온 **수기 족보 노트**를 디지털로 옮겨 보존하고, 웹으로 가족들과 공유하기 위한 저장소입니다.

- 웹 족보 본문: [index.html](index.html) — GitHub Pages로 서빙 (아래 [웹으로 보기](#웹으로-보기-github-pages) 참고)
- 수기 원본 전사·오류 대조표: [원본대조.md](원본대조.md)
- 수기 원본 사진: [reference/](reference/)

## 이 저장소가 만들어진 과정

1. **수기 원본** — 스프링 노트 3펼침면에 ① 조선왕조 계보, ② 전주이씨 해안군 정희공파 세보(1~16세), ③ 직계 4대(12~15세) 생몰·묘소와 이한석·최공녀 가계도가 손글씨로 기록되어 있었다.
2. **1차 디지털화 (2026년 5월)** — 당시 촬영한 노트 사진을 바탕으로 단일 파일 웹 족보(`index.html`, 한지 스타일)를 만들었다. 이 과정에서 손글씨 판독 오류가 다수 들어갔다 (예: "해안군 정희공파"→"해안대군파", "이병근"→"이번순", "최공녀"→"허공녀", "국립서울현충원"→"구읍시면 현춘천").
3. **원본 재판독 (2026년 8월 29일)** — 노트를 재촬영한 사진 3장을 `reference/`에 보관하고, 사진 부분 확대 → 역사 기록 교차검증(해안군의 생몰·자(字)·모친·아들 6군이 실제 기록과 일치함을 확인) → 가족 확인 문답(12개 항목) 순서로 전면 재판독했다. 결과는 [원본대조.md](원본대조.md)에 정리했다.
4. **오류 수정 + 디자인 개편 (2026년 8월 29일)** — 원본대조.md의 수정 체크리스트(§6)를 전부 `index.html`에 반영했다. 아울러 전통 궁궐 포스터 무드(어두운 밤하늘 + 금빛 실루엣 + 달·구름·물결 문양)를 참고해 **달빛 야경 테마**로 재디자인했다. 그림 요소는 저작권 문제가 없도록 전부 오리지널 SVG로 직접 그렸고, 참고한 외부 이미지는 `Images/` 폴더에 둔다.
5. **인쇄 족보 한자 판독 (2026년 8월 30일)** — 집안에 전해오는 **인쇄 족보** 『全州李氏 海安君 靖僖公派世譜』(天卷) 사진 16장을 확대 판독해, 지금까지 한글로만 남아 있던 **1~16세 인명의 한자**를 채웠다. 세대마다 이어지는 **항렬자**(3세 虎 → 5세 壽 → 8세 昌 → 9세 東 → 10세 宅 → 11세 尙 → 12세 炳 → 13세 基 → 14세 鎬 → 15세 漢 → 16세 榮 → 17세 炯 → 18세 埈)가 판독의 교차 검증축이 되었다. 결과는 [원본대조.md §8](원본대조.md)에 정리했고, 이 과정에서 오래 남아 있던 미확정 항목 4건이 해결됐다.
   - 13세 **기보(基輔) = 이윤삼(初諱 允三)** 동일인 확정
   - 14세 **철호(喆鎬) · 초휘 봉길(鳳吉)** 확정
   - 이한규의 배우자 = **밀양박씨 옥례(密陽朴氏)**
   - 수기 노트의 '현호'는 **호영(虎榮)의 초명 현호(顯虎)**
6. **화면 개편 (2026년 8월 30일)** — PC에서 **한 화면에 한 장(章)씩** 보는 페이지 모드, 노트 그림을 옮긴 **왕통 가지도** 장, 왕통 노선도의 **왕릉 사진 + 묘 위치** 표기, **용어집** 장, 그리고 별도 인쇄판 `print.html`을 추가했다. 인쇄본은 종이로 출력해 손 교정한 것을 다시 반영했다(2026-09-05, 원본 `photos/re/`).
7. **미결 항목 관리 (2026년 8월 30일부터)** — 확인되지 않은 항목은 **웹 족보에 싣지 않는다.** 가족이 보는 페이지에 불확실한 내용을 두지 않기 위해서다. 남은 항목은 [원본대조.md §7](원본대조.md)에서만 관리하고, 확인이 끝난 것만 `index.html`·`print.html`로 옮긴다.

## 웹 족보의 구성 (장 章)

| 장 | 내용 |
|---|---|
| 표지 | 궁궐 야경 사진 위에 제목·엮음 정보. 사진이 없으면 자동으로 SVG 야경 그림으로 되돌아간다 |
| 서문 | 이 족보가 만들어진 경위 |
| 조선왕조 계보 | 추존 4조 + **27대 왕통 노선도** — 왕마다 능(陵)·묘 사진과 능호·위치, 어진이 전하는 6위는 오른쪽에 어진을 덧붙였다. 해안군까지가 기본 표시이고 그 뒤 16대는 「펼쳐 보기」로 연다 |
| 왕통 가지도 | 수기 노트의 가지 그림을 목조부터 순종까지 **끊지 않고 한 그루로** 옮긴 도식. 태조에서 해안군까지의 길은 늘 붉은 선으로 켜 두었고, 마디에 마우스를 올리면 시조부터 그 인물까지의 길이 금색으로 켜진다. 노선도 제목 옆 「가지도로 보기」로 오간다 |
| 정희공파 세보 | 1~16세 세계 + **한자 병기**. 우리 직계는 붉은 글씨로 표시 |
| 직계 | 12~17세 카드 — 생몰·묘소·배위·한자 |
| 친족 가계도 | 이한석·최공녀의 자손 전체 도식 |
| **용어집** | 추존·묘호·항렬자·초휘 같은 말 29개를 뜻과 «이 족보에서의 실제 예»로 풀었다. 본문에 나오는 용어에는 점선 밑줄이 자동으로 붙고, 누르면 그 자리에서 뜻이 뜬다 |
| 기록 출처 | 원본 자료·판독 방법·사진 라이선스 |

### 두 도식은 「축소본 → 전체 화면」

「왕통 가지도」와 「친족 가계도 — 4대 가계도」는 폭이 넓어 화면에 다 들어오지 않는다. 그래서 **전체 모양이 한눈에 들어오는 축소본**을 먼저 보여 주고, 누르면 **전체 화면 팝업**으로 열린다.

- 팝업에서 드래그로 이동, `Ctrl`+휠 또는 `＋`/`−` 버튼으로 확대·축소
- 「한 눈에」로 전체 맞춤, 「원래 크기」로 100%, `Esc`로 닫기

### PC 화면 — 페이지 모드

가로 1100px 이상에서는 **한 화면에 한 장씩** 보이고, 장 안에서만 스크롤된다.
- 왼쪽 사이드바 또는 아래 「← 이전 / 다음 →」 막대로 이동
- **← →** 방향키로도 넘길 수 있다
- 사이드바 아래 「한 화면씩 보기」 버튼으로 예전처럼 쭉 이어지는 화면으로 되돌릴 수 있다
- 좁은 화면(모바일·태블릿)에서는 지금까지처럼 전체가 이어져 스크롤된다

## 인쇄 — [`print.html`](print.html)

**어르신께 종이로 드릴 때는 웹 화면이 아니라 [인쇄본 페이지](print.html)를 쓴다.** 사이드바 아래 「인쇄본 열기」로 열린다.

웹 족보는 어두운 배경·사진·가로로 긴 도식이 많아 그대로 뽑으면 잘리고 잉크도 많이 든다. 인쇄본은 그것들을 걷어내고 **내용만 A4 9장에 맞춰 다시 짠 별도 문서**다.

| | |
|---|---|
| 판형 | A4 세로 9장. 배경 그래픽 인쇄 설정을 켜지 않아도 그대로 나온다 |
| 구성 | 표지(목차) · 조선왕조 27대 · 추존왕과 대원군 · 우리 집안 한눈에 보기 · 세보·직계 1~11세 · 12~18세 · 용어집(2장) · 친족 가계도 |
| 특징 | 쪽번호와 목차가 자동으로 매겨져, 내용을 늘리거나 줄여도 손댈 곳이 없다 |

웹 화면 자체를 인쇄해야 할 때는 사이드바의 「이 화면 그대로 인쇄」를 쓸 수 있다(접어 둔 왕통 구간은 인쇄 시 자동으로 펼쳐진다).

## 인물 사진 넣기

직계 카드(12세~17세)에는 사진 자리(도장 모양 플레이스홀더)가 잡혀 있다. 사진이 준비되면:

1. `photos/` 폴더에 `15_이한석.jpg`처럼 **`세대_이름.jpg`** 형식으로 저장 (세로 3:4 비율 권장)
2. `index.html`에서 해당 인물 카드의 플레이스홀더를 이미지로 교체:

```html
<!-- 교체 전 -->
<div class="portrait"><span class="pseal">이한석</span><span class="ph-note">사진 준비 중</span></div>
<!-- 교체 후 -->
<div class="portrait"><img src="photos/15_이한석.jpg" alt="이한석"></div>
```

3. 커밋·푸시하면 Pages에 반영된다.

왕통 노선도의 왕 초상은 위키미디어 공용의 퍼블릭 도메인 이미지(현존 어진·구한말 사진)를 직링크로 쓰며, 어진이 전하지 않는 왕은 묘호 메달리온으로 표기한다.

1. [원본대조.md](원본대조.md)를 열고 §6 체크리스트를 따라간다.

## 웹으로 보기 (GitHub Pages)

최초 1회 설정:

1. GitHub에서 이 저장소 → **Settings → Pages**
2. *Build and deployment* 의 **Source**: `Deploy from a branch`
3. **Branch**: `main`, 폴더 `/ (root)` 선택 → **Save**
4. 1~2분 후 아래 주소로 접속:

```
https://namejaesung.github.io/family-genealogy/
```

- 휴대폰·태블릿 등 어떤 기기에서든 위 주소로 접속하면 된다 (index.html이 모바일 반응형).
- 가족에게는 카카오톡 등으로 링크를 공유하면 되고, 휴대폰 브라우저의 **"홈 화면에 추가"**를 쓰면 앱처럼 쓸 수 있다.
- 이후에는 `main` 브랜치에 푸시할 때마다 자동으로 갱신된다.

### ⚠️ 공개 범위 주의

- GitHub Pages 사이트는 **주소를 아는 누구나 볼 수 있는 공개 페이지**이며, 무료 플랜에서는 **Public 저장소에서만** Pages를 쓸 수 있다. 즉 저장소의 원본 사진과 문서까지 모두 공개된다.
- 이 저장소에는 **생존 가족의 실명·생년월일·가족관계**가 담겨 있으므로 공개 전에 다음을 고려할 것:
  - 검색엔진 노출이라도 막으려면 `index.html`의 `<head>`에 `<meta name="robots" content="noindex">` 추가
  - 더 안전하게 하려면: 생년월일·생존 인물 이름을 마스킹한 공개판을 별도로 만들거나, 접근 제한을 걸 수 있는 호스팅(Cloudflare Pages + Access의 이메일 인증 등) 사용
